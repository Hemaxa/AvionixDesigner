## Три главных различия

1. **Объект редактора** хранит удобные для редактирования данные и умеет рисовать себя через Qt. Его класс наследуется от `BaseObject`.
2. **Аппаратная сцена** содержит слова параметров и банки памяти для ПЛИС. Один объект редактора может превратиться в несколько аппаратных слов или этапов.
3. **Пакет UART** — уже готовые байты протокола с заголовком и контрольной суммой. Пакеты формируются до открытия порта.

Глазик видимости в редакторе, флаг экспорта и аппаратный `enb` выполняют разные задачи. Эти понятия подробно разобраны в главах 3–5.
