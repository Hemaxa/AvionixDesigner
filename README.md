# AvionixDesigner

Визуальный редактор интерфейсов для графического контроллера на базе ПЛИС. Приложение разделяет редактируемый проект и экспортный XML для железа: внутри редактора объекты остаются удобными исходниками, а при экспорте преобразуются в фиксированные параметры, растровые маски и атласы шрифтов.

## Форматы

### `.avd`

Внутренний проектный формат AvionixDesigner. Файл `.avd` является ZIP-контейнером с `project.json` и папкой `assets/`. Сейчас растровые маски дублируются внутри JSON как PNG/base64 для простого восстановления проекта; папка `assets/` уже зарезервирована под вынос исходников изображений и SVG на следующем шаге развития формата.

В `.avd` разрешено обычное редактирование: перемещение, изменение размеров параметрических объектов, импорт PNG/JPEG/BMP/SVG, настройка цвета и текста. Текст пока ограничен Arial 14, но структура объекта уже хранит семейство, размер, индекс шрифта и кернинг.

### `.xml`

Импортный и экспортный формат ПЛИС. XML содержит только то, что может прочитать графический контроллер: 150-битные параметры модулей, статические прямоугольные объекты, растровые маски прозрачности `0..7` и текстовые атласы в `<fonts>`.

Команда `Сохранить кадр для ПЛИС...` экспортирует текущую сцену в XML. Текст экспортируется в блок `<symbols>` и сопровождается `<font>` с глифами `<digit>` / `<upper>`, где каждая строка маски состоит из цифр `0..7`.

## Ограниченный режим XML

При открытии готового XML приложение переходит в режим ограниченного редактирования.

Параметрические объекты `Rectangle`, `DashedLine`, `RibbonScale`, `AviaHorizon` остаются редактируемыми.

Растровые объекты `StaticGroup` и `RotationObject` нельзя масштабировать или менять через размерные ручки. Доступны перемещение, цвет, видимость и вращение для `RotationObject`.

Текстовые объекты блокируют шрифт и размер. Строку можно менять только символами, которые уже есть в импортированном атласе XML. При вводе отсутствующего символа редактор показывает предупреждение.

## Интерфейс

- `Файл -> Создать...` создаёт редактируемый проект `.avd`.
- `Файл -> Открыть...` открывает `.avd` или FPGA `.xml`.
- `Файл -> Сохранить кадр для ПЛИС...` экспортирует XML для железа.
- `Файл -> Добавить изображение...` импортирует растровое изображение или SVG как `staticgroup`.
- Изображения также можно перетащить прямо на холст.
- Переключатель тем удалён; приложение использует единый стиль `AvionixTheme.qss`.

## Сборка и запуск

```bash
cd /path/to/AvionixDesigner
cmake -S . -B build
cmake --build build
./build/AvionixDesigner.app/Contents/MacOS/AvionixDesigner
```

## Основные классы

- `ProjectManager` управляет жизненным циклом проекта, режимом редактирования, импортом `.avd`/`.xml`, экспортом FPGA XML и добавлением изображений.
- `EditorProjectDocument` хранит метаданные сцены: имя проекта, размер холста и фон.
- `FpgaSchemaRegistry` описывает битовые схемы модулей ПЛИС и соответствие тегов XML классам редактора.
- `BaseObject` задаёт общий интерфейс объектов и флаги ограниченного режима.
- `StaticGroupObject` и `RotationObject` работают с растровыми масками `0..7` и BRAM-адресами.
- `TextObject` поддерживает редактируемый Arial 14 и импортированный FPGA-атлас с проверкой допустимых символов.
- `ViewportPanel` отвечает за отображение холста, выделение, перемещение, resize/rotate-манипуляторы и drag-and-drop изображений.
- `ObjectLibraryPanel` содержит кнопки добавления объектов и импорта изображений.
- `ObjectPropertiesPanel` редактирует свойства выбранного объекта и показывает предупреждения при нарушении ограничений XML.

## Структура проекта

```text
AvionixDesigner/
├── CMakeLists.txt
├── README.md
├── docs/                  # Документация модулей ПЛИС и эталонные XML
├── res/
│   ├── icons/             # Иконки интерфейса
│   ├── themes/
│   │   └── AvionixTheme.qss
│   └── resources.qrc
└── src/
    ├── editor/            # Внутренняя модель проекта
    ├── managers/          # ProjectManager, AppearanceManager, ObjectsManager
    ├── objects/           # Реализации объектов сцены
    ├── panels/            # Панели редактора
    ├── schema/            # FPGA-схемы параметров
    ├── utils/             # BitParser, XmlReader, DebugDumper
    └── windows/           # Главное окно и диалоги
```
